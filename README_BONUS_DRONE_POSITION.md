# Bonus update: predicted drone path layer

This update adds:

- `gps_ex1.tools.change_prediction_target`
- an improved `gps_ex1.tools.export_kml` that labels prediction layers as center-point or drone-position paths
- KML visualization helpers, in case they were not already installed

Use it to create a predicted drone path for DJI_0010 / DJI_0011 and show it together with the predicted camera-center path in Google Earth.
